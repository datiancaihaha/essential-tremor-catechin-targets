
# Input schema

Required ET GWAS fields are chromosome, base-pair position, SNP/rsID, effect-size or P-value field, and sample-size information required by the configured MAGMA command. Gene definitions use NCBI build 37.3 with 35-kb upstream and 10-kb downstream windows. The LD reference is 1000 Genomes European. Target-set membership files contain set identifier and approved gene symbol.
