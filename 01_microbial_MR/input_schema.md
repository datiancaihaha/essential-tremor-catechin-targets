
# Input schema

## Microbial exposure statistics

Required fields: taxon identifier, SNP/rsID, effect allele, other allele, exposure beta, exposure standard error, exposure P value, and sample size when supplied. Exposure effect-allele frequency was unavailable; palindromic variants were therefore excluded during harmonization.

## Essential-tremor outcome statistics

Required fields: SNP/rsID, effect allele, other allele, log-odds beta, standard error, P value, and case/control sample sizes. The manuscript analysis used deCODE summary statistics under the provider's access terms. Users must supply their authorized local copy; it is not redistributed here.

## Linkage-disequilibrium reference

1000 Genomes Project phase 3 European reference genotypes, used for clumping at r2 < 0.001 within 10,000 kb.
