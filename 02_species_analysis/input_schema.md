
# Input schema

Species exposure files require a species identifier, SNP/rsID, effect and other alleles, beta, standard error, P value, effect-allele frequency when available, and sample size. Essential-tremor outcome fields match `01_microbial_MR/input_schema.md`. Instrument clumping used r2 < 0.001 within 10,000 kb, with exposure P < 5e-6 and F >= 10.
