
# Input schema

Each chemical form is represented by a stable form identifier, exact stereochemical or unspecified structure label, canonical/isomeric SMILES, InChIKey where available, and database identifier. Prediction outputs require target name, approved gene symbol, organism, method-specific probability or score, and source method. Experimental annotations require database, exact-structure match, assay identifier, target identifier, activity type/value/units, and evidence classification.
